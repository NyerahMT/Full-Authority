OpenStreetMap geometry
----------------------
Building and road geometry is derived from OpenStreetMap data distributed by Geofabrik.
© OpenStreetMap contributors. OpenStreetMap data is licensed under the Open Data Commons
Open Database License (ODbL) 1.0: https://www.openstreetmap.org/copyright

Baked Stage 021 vector database
-------------------------------
stage021_malta_world.bin is a transformed/optimized database derived from the OSM source
above. Keep this attribution with redistributed copies of the baked database and comply
with the ODbL requirements applicable to database redistribution.

Elevation
---------
Terrain heights are sampled from the Mapzen/Tilezen Terrain Tiles public dataset hosted
in the AWS Open Data Registry. Terrain Tiles combine multiple elevation sources; source-
specific attribution requirements are documented by Tilezen/joerd:
https://github.com/tilezen/joerd/blob/master/docs/attribution.md

The Stage 021 code itself is separate from these third-party data licenses.
